# 2ème cercle — Vue d'ensemble

Le 2ème cercle introduit la **manipulation avancée du chakra** : ériger des barrières, soumettre des animaux, accumuler du chakra. Chaque sceau demande **2 à 4 kanjis**.

## Sceaux du 2ème cercle

* [Sceau de barrière](barriere.md)
* [Sceau de dressage](dressage.md)
* [Accumulation de chakra](accumulation-de-chakra.md)

## Kanjis obligatoires (2 à 4 kanjis)

| Sceau | Kanji(s) | Signification |
|---|---|---|
| Barrière physique | 防 / 界 | protection / limite, séparation |
| Dressage | 従 (Jū) | obéissance / suivre |
| Accumulation de chakra | 蓄 (chiku) | accumuler |
