# 1er cercle — Vue d'ensemble

Le 1er cercle regroupe les **sceaux fondamentaux** du Fuinjutsu. Ils posent les bases du scellement : stocker, enfermer, verrouiller. Chaque sceau de ce cercle demande **2 kanjis minimum** et un **Roll > 50** (en dessous du 3ème cercle).

## Sceaux du 1er cercle

* [Sceau de stockage](sceau-de-stockage.md)
* [Emprisonnement du feu](emprisonnement-du-feu.md)
* [Emprisonnement du chakra](emprisonnement-du-chakra.md)
* [Sceau de verrouillage](verrouillage.md)

## Kanjis obligatoires (2 kanjis minimum)

| Sceau | Kanji principal | Signification |
|---|---|---|
| Sceau de stockage | 蔵 | stockage |
| Emprisonnement du feu | 封 (Fū) | sceller / verrouiller |
| Emprisonnement du chakra | 封 (Fū) | sceller / verrouiller |
| Verrouillage | 錠 | verrou / cadenas |
