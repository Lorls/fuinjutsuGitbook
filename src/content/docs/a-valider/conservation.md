## Définition

Sceau qui **suspend la dégradation** d'un objet inerte — nourriture, échantillon, sang, médicament — pour le conserver intact dans le temps.

## Kanjis

Deux kanjis formant le mot **保存** (hozon, « conservation ») :

- **保** — préserver / protéger
- **存** — conserver / maintenir

## Règles

- **Contact direct** avec l'objet.
- **Objets inertes uniquement** (pas d'être vivant).
- **Suspend la dégradation** tant que le sceau tient.
- **Ne restaure pas** ce qui est déjà abîmé.
