| 1er cercle | 蔵 (stockage) | > 50 (en dessous du 3ème cercle) |

## Définition

Sceau permettant de **stocker des objets matériels** dans un espace dimensionnel compact via du chakra. L'objet est aspiré dans le sceau et peut être **invoqué à tout moment**.

## Kanjis

- **蔵** — stockage

## Règles

- **Contact requis** : objet → sceau → utilisateur pour stocker.
- La **taille** de ce qui peut être stocké dépend du niveau du pratiquant.
- **Interdit** sur les êtres vivants animaux (humains compris).
- Le sceau ne peut **pas être placé sur un être humain**.
- Seul l'**utilisateur du sceau** peut accéder à son sceau : il ne peut pas être forcé par un autre utilisateur.
