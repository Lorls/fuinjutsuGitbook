## Définition

Sceau qui permet d'**emprisonner une personne dans un sceau**, une autre dimension dans laquelle elle est **coupée du monde extérieur**. C'est représenté comme une **prison de chakra**.

## Kanjis

Cinq kanjis — sceller le prisonnier dans une dimension-geôle :

- **囚** — prisonnier / captif
- **封** — sceller
- **印** — sceau / marque
- **獄** — prison / geôle
- **界** — dimension / monde

## Règles

- Nécessite un **contact physique** entre l'utilisateur → sceau → cible.
- La cible doit être **en pain** ou **d'accord**.
- La personne ne peut **pas être emprisonnée indéfiniment** (prison d'**1h**).
- Demande la **présence d'un staff** sur la scène + **validation préalable**.
- Possible uniquement sur **N+1 maximum**.
- Garder une **preuve de chaque pose** : enregistrement recommandé.
