## Définition

Sceau utilisé pour **immobiliser temporairement les muscles** d'une personne.

## Kanjis

Le cœur forme le mot **束縛** (sokubaku, « entrave »), appliqué aux muscles :

- **束** — attacher / entraver
- **縛** (Baku / Shibaru) — lier
- **筋** — muscle
- **止** — arrêter / immobiliser

## Règles

- Appliqué **directement sur la cible** ou sur une **surface en contact** avec elle.
- Si application directe : la cible doit être **en pain** ou **en accord**.
- Préciser les **restrictions dans le `/it`**.
- **Durée maximale : 30 min** sur une cible du même niveau que soi.
  - **+ 10 min** par différence de grade en faveur du poseur.
  - **Divisée par 2** pour les grades supérieurs (ex : TKJ → Jonin = 15 min).
- **Pas sur les muscles vitaux**.
- N'interrompt **pas** les actions ne nécessitant pas de mouvement (comme le genjutsu).
- Garder une **preuve de chaque pose** : enregistrement recommandé.
